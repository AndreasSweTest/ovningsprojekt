# /tdd

1. Skriv ett fallerande test som beskriver önskat beteende.
2. Kör testerna och visa att det är rött.
3. Skriv minsta möjliga kod för att bli grön.
4. Kör testerna igen.
5. Refaktorera om behövs (behåll grönt).
6. Committa med meddelande som börjar med "test: " eller "feat: ".

Ta aldrig bort eller stäng av tester.
